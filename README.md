# AI Learning Atlas

A responsive AI learning roadmap with linked courses, projects, a study planner, and browser-local progress.

## Publish with GitHub Pages

In this repository, open Settings → Pages. Select **Deploy from a branch**, choose **main**, select **/ (root)**, then Save.

Expected website address after deployment: https://rava2002.github.io/AI-Learning-lessons/

Progress is stored in each browser. Export a backup from the local website and import it on the hosted website to transfer your progress.

## Local preview

Run `python -m http.server 4173` from this folder, then open http://localhost:4173.
